# t7xapps.com

Site estático da T7X Technologies LLC, no GitHub Pages (branch `main`, raiz). Sem build: é só editar e fazer push.

- `/` — empresa, apps e contato
- `/arcana/` — página do Arcana
- `/arcana/privacy/` — política de privacidade (PT, EN, ES; `?lang=pt|en|es`)
- `/terms/` — termos de uso (PT, EN, ES)
- `/app-ads.txt` — vendedores autorizados (AdMob)
- `assets/` — estilo (direção A: Space Grotesk + Inter, fundo #07080C, roxo #8B7CFF), script de idioma e ícones
- `design/direcao-a.html` — referência visual aprovada pelo Thiago

Topo e rodapé se repetem em todas as páginas: ao mudar um, mude em todas. Todo texto visível tem versão PT, EN e ES (`data-l="pt|en|es"`).
